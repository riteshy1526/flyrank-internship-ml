An end-to-end machine-learning decision-support project for prioritising content-refresh opportunities using anonymised content-page data.

01
QUESTION

Can machine-learning signals support content-refresh prioritisation?

This project investigates whether measurable content, search-performance, engagement, and freshness signals can provide a useful directional ranking signal for identifying content opportunities.

02
DATA

Dataset & Features

30,000 Content-page records
44 Dataset fields
NDCG Ranking evaluation metric

The public project uses an anonymised content-page dataset. Features include search demand, competition, content length, traffic performance, engagement, freshness, and historical trend signals.

Search Volume Competition Traffic CTR Engagement Content Age Freshness Trend
03
METHODOLOGY

From Baseline to Machine Learning

01

Data Preparation

Feature selection, missing-value handling, and preparation of the modelling dataset.

02

Baseline

A transparent rule-based scoring approach was used as the comparison baseline.

03

Random Forest

A Random Forest regression model was trained using the selected measurable signals.

04

Grouped Validation

Client-grouped validation was used to avoid client overlap between training and testing.

04
RESULTS

Model vs Baseline

Both approaches were evaluated on the same held-out client-grouped test split using NDCG.

Baseline NDCG 0.9999
Random Forest NDCG 0.9971
Difference -0.0028

NDCG Comparison

Key finding

On the evaluated split, the transparent baseline slightly outperformed the Random Forest model. This shows that a more complex model does not automatically provide a better ranking signal.

05
MODEL INTERPRETATION

Feature Importance

Random Forest feature importance provides an indication of which input signals contributed most to the model's predictions on the evaluated dataset.

06
LIMITATIONS

Honest Framing

Observed, not guaranteed

Results describe performance on the evaluated anonymised dataset and should not be treated as guaranteed real-world outcomes.

Validation scope

Client-grouped validation reduces client overlap, but broader temporal and production validation would be needed before deployment.

Decision support

The model should be considered a directional decision-support signal rather than an automatic content-refresh decision maker.

07
ACTION PLAYBOOK

Ranked Recommendations

01

Use transparent signals first

Start with measurable freshness, traffic-trend, CTR, and content-age signals when prioritising reviews.

02

Validate before acting

Review high-ranked pages with additional business and content context before deciding to refresh them.

03

Prefer evidence over complexity

Compare machine-learning models against simple baselines instead of assuming that a more complex model is automatically better.
